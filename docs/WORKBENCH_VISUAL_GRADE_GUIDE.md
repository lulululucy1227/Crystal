# Crystal Workbench 视觉识别与品质分档指南

> 目的：用于 GPT 搜图、筛图、后续抠图和工作台展示。这里的 `低 / 中 / 高` 是**视觉品质参考层级**，不是统一市场证书等级，也不等同于售价等级。
>
> 原则：先保证“一眼能认出是什么品种”，再表现品质差异；如某品种更适合按光效/类型/图案区分，则禁止硬套低中高。

## 二、珍珠 / 天然材质

珍珠不采用“透明度”逻辑，主要看：**光泽、圆度、表皮、颜色、尺寸与匹配度**。

| 中文名 | English | 展示模式 | 主要识别特征 | 低 | 中 | 高 |
|---|---|---|---|---|---|---|
| 白色淡水珍珠 | White Freshwater Pearl | 低/中/高 | 白/奶白、常见轻微不圆 | 光泽弱、表皮瑕疵明显 | 光泽好、形状较协调 | 光泽锐利、表皮干净、匹配度高 |
| Akoya 珍珠 | Akoya Pearl | 低/中/高 | 圆度高、冷白/银白、高镜面感 | 光泽软、表面瑕疵明显 | 圆度与光泽良好 | 镜面光强、圆度高、表皮洁净 |
| 白色南洋珠 | White South Sea Pearl | 低/中/高 | 大尺寸、白至银白、厚重光泽 | 光泽普通、表皮纹多 | 大颗、光泽稳定 | 大尺寸 + 强光泽 + 洁净表皮 |
| 金色南洋珠 | Golden South Sea Pearl | 低/中/高 | 金黄至香槟金体色 | 色浅发灰、光泽弱 | 金色明确 | 金色浓郁、均匀、光泽强 |
| 大溪地珍珠 | Tahitian Pearl | 色调 + 品质 | 深灰/黑灰、孔雀绿等伴色 | 体色平、伴色弱 | 有明确伴色与光泽 | 孔雀绿/银灰等伴色强、镜面感好 |
| 巴洛克珍珠 | Baroque Pearl | 形态品质 | 不规则天然形状 | 形状杂乱且缺乏美感 | 有明显个性轮廓 | 形态独特且构图美、光泽强 |
| 深色木/沉香类结构件 | Dark wood / agarwood-like spacer | 类型/纹理 | 深棕至黑棕、天然木纹 | 不做统一宝石等级 | 重点展示纹理、表面处理和色调 | — |

## 三、配饰 / 结构件

配饰不做“宝石低中高”，采用 `结构类型 + 表面品质 + 设计语言`：

- 925 银微型隔珠 / Sterling Silver Micro Spacer
- 弯管 / Curved Silver Tube
- 薄框 / Bezel / Thin Frame
- 半帽 / Half-cap / Edge-cap
- 几何连接件 / Geometric Connector
- 小银球 / Counterweight Sphere
- 极细银链 + 极简扣件 / Fine Chain + Minimal Clasp
- 小型抽象/植物吊坠 / Abstract or Botanical Charm
- 氧化银微型点缀 / Oxidized Silver Accent

工作台图片要求：
1. 银色必须是中性银白，不做廉价高亮镀铬效果；
2. 结构轮廓一眼可识别；
3. 单件或少量组合，尽量透明背景；
4. 不使用复杂华丽古董件冒充 V1 极简结构件。

## 四、包装

包装以 `结构 / 材质 / 配色` 识别，不做低中高宝石式分档：

- 哑光白 / 冷白硬盒 / Matte White Rigid Box
- 冷灰抽屉盒 / Cool Grey Drawer Box
- 柔灰 / 珍珠白保护袋 / Soft Grey or Pearl-white Pouch
- 材质说明与护理卡 / Material Disclosure + Care Card
- 品牌保护邮寄袋 / Protective Branded Mailer
- 棉麻信封袋 / Cotton-linen Envelope Pouch
- 极简书型磁吸盒 / Minimal Book-style Magnetic Box
- One-of-One 证书卡 / One-of-One Certificate Card

最终工作台素材应保持：**冷白、冷灰、低饱和米灰、克制编辑感**。即使合法参考图是棕色、红色或金色，也只用于结构参考，不代表 Crystal 最终视觉配色。

## 五、GPT 搜图/筛图验收规则

每个正式工作台素材至少满足：

1. 一眼能辨认品种/结构类型；
2. 视觉特征与本指南一致；
3. 不通过过度调色伪造材质；
4. 如有低/中/高图组，三者差异必须落在同一组 `quality_axes` 上；
5. 来源许可允许再分发和修改后，才可进入公开 GitHub 二进制素材库；
6. 电商/供应商图可进入 `visual evidence`，但版权不明时不得复制到 GitHub；
7. 中文为主，英文仅作标准名称对照。
