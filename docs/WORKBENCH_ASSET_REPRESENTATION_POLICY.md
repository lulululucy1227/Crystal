# Crystal Workbench 素材表现政策 V1

日期：2026-09-01
负责人：GPT Crystal Supervisor

## 1. 核心原则

Crystal Workbench 的素材目标不是“完全真实拍照”，而是：

> 一眼能识别品种，同时在适用时能看出视觉品质差异，并且能够在同一工作台中统一展示。

因此，素材真实性的优先级低于“品种特征准确性 + 可比性 + 一致性”，但任何标准化处理都不得改变材料的真实识别逻辑。

## 2. 三层素材体系

### A. Evidence / 参考证据层

来源：Wikimedia Commons、博物馆 Open Access、学术/矿物资料、市场实物图。

用途：
- 判断真实颜色范围；
- 判断透明度、包裹体、光效、纹理；
- 判断同品种低/中/高的视觉差异；
- 为最终展示素材提供事实依据。

版权不明确的市场图只能停留在本层，禁止复制二进制到公开 GitHub。

### B. Display / 工作台展示层

这是工作台默认看到的图片。

允许：
- 抠图；
- 去背景；
- 统一画布；
- 统一裁切；
- 轻度曝光/白平衡校正；
- 多个合法参考素材综合后生成标准化代表图；
- GPT 生成的代表性展示图，只要其特征受 Evidence 层约束。

必须：
- 中文名为主；
- 英文作小字对照；
- 标记素材是 `source_photo`、`processed_source_photo`、`generated_from_evidence` 或 `composed_from_real_bead_cutout`；
- 不把生成图标成“实拍”。

### C. Grade comparison / 品质对比层

适用于确实存在稳定视觉品质差异的材料。

默认使用：
- `low_reference`
- `mid_reference`
- `high_reference`

这些只是“视觉品质参考”，不是统一市场价格等级，也不是供应商 AA/AAA 等级。

## 3. 不同材料采用不同分档逻辑

### 低/中/高适用

白水晶、茶晶、海蓝宝、紫水晶、黄水晶、粉水晶、蓝纹玛瑙、紫锂辉、金发晶、黑发晶、海纹石、Akoya/南洋/大溪地等珍珠。

### Pattern / effect 优先

绿幽灵、白幽灵、综合色发晶、血石。

### Type 优先，不硬分低中高

黑曜石：普通黑曜 / 彩虹黑曜 / 金曜 / 银曜。

### Optical effect 优先

拉长石、彩虹月光石、虎眼石：优先表现光效强弱、覆盖率、光带连续性。

## 4. 生成/标准化素材的真实性边界

可以为了识别性强化：
- 把真实存在但在原图中不明显的光效以合理拍摄条件表现出来；
- 把多个真实样本的共同特征合成一个“标准代表图”；
- 统一背景和物体尺度。

禁止：
- 把海蓝宝做成不自然的霓虹蓝；
- 把绿幽灵做成普通实心绿色珠；
- 把黑发晶做成黑色染色石；
- 把虎眼石光带画成金属高光；
- 把月光石/拉长石做成全表面均匀发光；
- 把珍珠修成无表皮、无层次的塑料球。

## 5. 工作台推荐展示结构

每个材料卡至少准备：

1. `hero`：最典型、最好识别的代表图；
2. `single`：单颗圆珠/单颗珍珠/单件配饰；
3. `grade_or_type_1`；
4. `grade_or_type_2`；
5. `grade_or_type_3`（如适用）。

对于 C_SIGNATURE 材料，可再增加 `collector_focal`。

## 6. 图片状态字段

所有正式素材必须有：

- `representation_type`
- `source_url`
- `source_site`
- `license`
- `can_redistribute`
- `can_modify`
- `grade_or_type`
- `recognition_features`
- `transformation`
- `processed_filename`
- `sha256`

## 7. 审美目标

最终图片应像“专业材料数据库 / 设计工作台”，而不是：
- 电商详情页；
- 灵性水晶宣传图；
- 过度闪亮的珠宝广告；
- 博物馆扫描档案的直接拼贴。

同一类别之间要有一致的光线、画布、缩放和留白，但必须保留品种差异。
