## 0. 证据分层

本 brief 严格区分：
- **visibility evidence**：编辑部、平台或卖家页面能看到某种设计语言正在出现；不等于销量。
- **demand evidence**：能看到购买、销售、购物车、评论等交易信号；本轮总体偏弱。
- **user reference**：用户 Drive 上传参考，仅证明用户收集过，不自动等于明确偏好。
- **explicit user preference**：只使用项目中已明确写下的审美边界，不从上传动作反推偏好。
- **Crystal recommendation**：基于以上证据做的独立设计建议。

当前外部证据的重要限制：2026 时尚编辑部明显确认了 bead / semiprecious-stone / mixed-bead 的可见度，但这类报道更偏女性时装和春夏最大主义；Crystal 不应直接复制“彩色、多层、堆叠”的 runway 表面风格。Harper’s Bazaar 将 mixed beads、unexpected colour、pearls/charms 和 semiprecious stones列为 2026 夏季可见趋势；Vogue 也把 beads 视为夏季主要配饰元素。Who What Wear 对 2026 runway 的总结同样强调 bead layering。它们支持“珠饰形式并不过时”，但不证明 Crystal 六主题任何具体材料能卖。

## 1. Mountain｜山

**可用视觉语言**：岩层、阴影、雾、雪线、断层、矿脉；低饱和灰/烟/土色中插入少量冷白或银；不是“棕色=山”。Drive REF-G02 的灰+木+浅色主石和 REF-G03 的灰蓝+银，可作为结构参考。

**容易廉价/俗套**：全串虎眼石、统一棕色 8mm、把山做成符号吊坠、满圈金属隔片、过度“户外男性”军事感。

**值得借鉴的结构**：非中心焦点；从深到浅的层级变化；局部尺寸跳变模拟岩层断裂；1 个异形/方形主石做“岩体”，而不是大圆珠居中。

**男性/中性机会**：高。灰、烟茶、墨黑、木、低光银能直接进入男性/中性语言；单串、低金属比、6–10mm 混合比纯 10mm 更现代。

**与 Crystal 基线冲突点**：若过度依赖木珠会滑向普通佛珠；若大量亮金或大虎眼会偏传统男性水晶串。

**设计 Agent 可直接转译**：
1. 做一款“雪线”：70–80% 深灰/烟色，小段冷白透明突然切入；
2. 做一款“断层”：一颗方/不规则焦点偏离中心，两侧 bead size 不对称；
3. 做一款“雾山”：同色系用透明度而不是色彩数量分层；
4. 银件只做 1–3 个结构节点，不做满圈隔片。

**证据强度**：visibility MEDIUM；demand LOW；user reference MEDIUM；Crystal recommendation HIGH。

## 2. Ocean｜海

**可用视觉语言**：深海蓝、海泡沫、湿润透明、黑蓝深度、波纹式不对称；允许“风暴海”而非只有浅蓝海滩。Drive REF-G05 的深蓝/黑/透明组合比传统粉蓝海洋串更有辨识度。

**容易廉价/俗套**：蓝白均匀交替、海星/贝壳吊坠、过量亮银海洋符号、浅蓝+白把产品做成旅游纪念品。

**值得借鉴的结构**：深浅段落而非全圈渐变；透明珠作为“水体留白”；一颗不规则透明或深蓝主石做潮汐重心；局部重复而非机械 ABAB。

**男性/中性机会**：中高。深蓝、烟灰、透明、极少银比海蓝宝+珍珠更中性；可把柔亮珍珠限制为 0–2 颗。

**与 Crystal 基线冲突点**：过分轻盈会和 Glacier 混成同一套蓝白串；Ocean 必须更“流动/深度”，Glacier 更“断裂/冻结”。

**设计 Agent 可直接转译**：
1. 至少一款采用深蓝→透明→深蓝的潮汐段落；
2. 一款使用非中心主石和不对称透明留白；
3. 一款用 2 种珠径模拟近岸/深水尺度；
4. 禁止三款都靠海蓝宝+白水晶实现主题。

**证据强度**：visibility MEDIUM；demand LOW；user reference MEDIUM（REF-G05）；Crystal recommendation HIGH。

## 3. Forest｜森林

**可用视觉语言**：深墨绿、苔藓纹理、灰绿、木、黑灰、低调银；更重要的是“有机纹理+阴影”，不是把所有绿色材料堆在一起。Etsy Tree Agate listing 说明树纹/枝状纹本身是市场可理解的森林语义，但这是单个卖家存在证据，不是销量证明。

**容易廉价/俗套**：绿东陵/孔雀石/木珠均匀串到底；叶子吊坠；大量“疗愈森林”宣传语言；传统佛珠排列。

**值得借鉴的结构**：木质段落和石质段落分区；一个方形/异形主石作为“树干/岩苔”；深色基底中少量半透明灰绿做空气层。Drive REF-G02 的木+灰+浅主石是很强的结构参考。

**男性/中性机会**：最高之一。木、墨绿、烟灰、哑银天然适合低调男性/中性表达。

**与 Crystal 基线冲突点**：最主要风险就是滑向普通沉香/佛珠；因此需要异形焦点、尺寸节奏或明显负空间打断传统规则。

**设计 Agent 可直接转译**：
1. 一款 40–55% 木珠，其余为深绿/灰石，但绝不全圈同珠径；
2. 一款方形深绿/黑灰主石偏置；
3. 一款几乎无金属，只用 1 个银色节点；
4. 用树纹/苔藓纹理做材料选择依据，而不是增加绿色数量。

**证据强度**：visibility MEDIUM；demand LOW；user reference HIGH（REF-G02）；Crystal recommendation HIGH。

## 4. Sunrise｜日出

**可用视觉语言**：黑夜→暖光→透明空气的“光比例变化”；金色不等于满圈黄；粉色只能是少量天空过渡。Drive REF-G01 的暖透明+弧形银件说明“光带/弧线”可以比太阳吊坠更高级。

**容易廉价/俗套**：粉+黄机械交替、太阳吊坠、橙黄高饱和满圈、玫瑰金+粉晶婚礼感。

**值得借鉴的结构**：暖色仅占 20–35%；主光点偏置；其余用烟灰、透明、乳白建立“天亮前后”；一条弧形或短金属段可充当地平线。

**男性/中性机会**：中。把暖色压低、引入茶烟/透明/银即可中性化；不应依赖粉晶。

**与 Crystal 基线冲突点**：暖色比例一高就会甜腻；亮金太多会变成传统财富水晶串。

**设计 Agent 可直接转译**：
1. 一款仅 3–5 颗暖色集中成光源，其余为冷灰/透明；
2. 一款用一颗暖色主石+两侧由深到浅的 3 段变化；
3. 一款采用银色弧形/短管件表达地平线，但金属总比低；
4. 不允许三款都使用黄水晶作为中心大珠。

**证据强度**：visibility MEDIUM（彩色/半宝石饰品在 2026 编辑部可见）；demand LOW；user reference MEDIUM（REF-G01）；Crystal recommendation HIGH。

## 5. Starlight｜星辰

**可用视觉语言**：夜空深度、微光、稀疏闪点、透明黑、灰黑、蓝闪、少量银白；重点是“暗面+稀疏光”，不是紫黑双色。Etsy Moon Phases / Violet Moonrise 能证明 celestial 语义在平台上持续可见，Moon Phases listing 还显示购物车信号，但单个 listing 不能外推市场销量。

**容易廉价/俗套**：紫水晶+黑曜石、星月吊坠堆叠、满圈闪珠、金色星星隔片、神秘学符号过量。

**值得借鉴的结构**：70–85% 暗基底；2–5 个高亮/蓝闪节点不规则分布；一段透明/烟透明负空间；微尺寸变化像星等。

**男性/中性机会**：高。REF-G06 的小颗烟黑透明单串是非常好的中性基线；在此之上加少量亮点即可成主题，而无需紫色。

**与 Crystal 基线冲突点**：如果沿用 REF-G04 的紫+黑+金+透明全部高对比，会过度戏剧化且接近常规玄学串。

**设计 Agent 可直接转译**：
1. 一款以烟黑透明小珠为底，仅 3 个银白/蓝闪“星点”；
2. 一款设置明显黑色留白段或深浅断点；
3. 一款用单颗拉长/异形主石当“天体”，其他珠保持小尺度；
4. 紫色若使用，总占比建议 <15%。

**证据强度**：visibility MEDIUM-HIGH；demand LOW-MEDIUM（仅 listing 级购物车/Star Seller 信号）；user reference HIGH（REF-G04/G06）；Crystal recommendation HIGH。

## 6. Glacier｜冰川

**可用视觉语言**：冻结、裂隙、乳白冰、透明冰、灰蓝阴影、磨砂与高透对比；与 Ocean 最大差异应来自“断裂/块体/静止”，不是颜色。

**容易廉价/俗套**：浅蓝+白水晶均匀交替；所有珠子高透明；雪花吊坠；大量 AB 彩光导致塑料感。

**值得借鉴的结构**：透明/磨砂交替；异形白/透明主石像冰块；尺寸突然变化模拟裂隙；更几何、更静态。Drive REF-G03 的灰蓝+银可以用作低色度基线，但需要打破其过度均匀的圆珠节奏。

**男性/中性机会**：中高。灰蓝、透明、哑银、磨砂都可做中性，关键是避免珠宝感过亮。

**与 Crystal 基线冲突点**：最容易与 Ocean 重合。Ocean = 流动、深浅、水体；Glacier = 块体、裂隙、冷静、几何。

**设计 Agent 可直接转译**：
1. 一款以磨砂白/灰蓝为主，仅少量高透“裂冰”；
2. 一款使用异形透明主石并在两侧做尺寸断裂；
3. 一款采取近对称结构，但故意在一个位置破坏对称形成“冰裂”；
4. 金属优先冷银，且比例低于 10–15%。

**证据强度**：visibility MEDIUM（半宝石/珠饰大类）；demand LOW；user reference MEDIUM（REF-G03）；Crystal recommendation HIGH。

## 7. 六主题结构/视觉模式矩阵

| Theme | 主结构 | 主光感 | 建议金属比 | 关键差异源 | 最需要避免 |
|---|---|---|---:|---|---|
| Mountain | 非对称层级/断层 | 烟、雾、雪线 | 低 | 岩层+尺寸断裂 | 棕色虎眼佛珠化 |
| Ocean | 流动段落/潮汐 | 深水+湿透 | 低-中 | 深浅与透明水体 | 蓝白旅游纪念品 |
| Forest | 石木分区/偏置焦点 | 阴影+有机纹理 | 极低-低 | 木+墨绿+异形 | 普通沉香/佛珠 |
| Sunrise | 光源集中/地平线 | 暖光穿透冷背景 | 低 | 暖色比例变化 | 粉黄甜腻 |
| Starlight | 暗底+稀疏星点 | 微闪/蓝闪/烟透明 | 极低-低 | 留白+星等 | 紫黑玄学套路 |
| Glacier | 近对称块体+裂隙 | 磨砂冰+高透裂冰 | 低 | 几何断裂 | 与 Ocean 同款蓝白 |

## 8. 给 18 款设计 Agent 的立即动作

当前设计任务仍未在 GitHub 出现正式 18 款设计包，因此不等待材料 Working Version。先把六主题结构差异做出来：每主题三款至少在 symmetry、focal strategy、bead-size rhythm、metal ratio 中两个维度发生变化。优先吸收 Drive 参考的“偏置焦点、材质分区、低金属、深浅层级”，不要复制其具体成品排列。

本轮最值得直接转译的三条：
1. **REF-G02**：Forest/Mountain 的灰+木+浅主石，不靠绿色/棕色标签，靠材质分区和偏置重心成立；
2. **REF-G06**：Starlight/男性线的低调小颗烟黑透明基线，说明“主题感可以由少量高亮节点产生”，无需紫黑大对比；
3. **REF-G03**：Glacier 的低色度灰蓝+银有效，但正式设计必须增加磨砂/透明和尺寸裂隙，否则会太均匀。

## 9. 证据限制

- 本轮没有取得可验证的欧洲主题级销售额、销量排名或转化数据，因此不得称任何六主题为“市场验证畅销”。
- 时尚编辑部证据主要证明 2026 bead / semiprecious / layered/mixed jewelry 的可见度，不代表 Crystal 应采用 maximalist 彩色风格。
- Etsy 是 listing / seller 级证据；Star Seller、in-cart、评论等信号只能用于低强度 demand evidence。
- Drive 文件是第三方社交截图。上传行为不等于明确喜欢，也不能从图片确认矿物真伪、处理、产地或等级。
