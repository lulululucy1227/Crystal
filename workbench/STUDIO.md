# Crystal Studio 使用与验收

本地 Windows 设计工具；圆盘与直槽是同一套逐颗设计的两种视图。不是商店，不写 canonical SQLite。

## 打开与设计

在项目目录运行 `npm.cmd run workbench`，打开终端显示的本地 HTTP 地址，等首页数据加载完成后选择“设计板”。不要直接双击 `index.html`。服务必须保持运行；不要在已有端口上强行启动第二个服务。

1. 设置手围、每圈余量和单圈／双圈／三圈。圆盘与直槽可随时切换，不复制珠子。
2. 右侧选材料、虚拟尺寸和形态；点击 `＋` 添加一颗，或拖到盘内指定位置。单击材料卡只激活材料，不跳页。
3. 散珠模式可分别拨动同一种材料的每一颗；圆盘与直槽分别记住散珠坐标。
4. “收拢成串”先显示顺序预览，确认后按连续顺序排列；不会按材料归组。成串后可拖到两颗之间插入／调整顺序，邻珠让位。直槽“全部／正手／背手”只筛选显示。
5. 点选珠子后打开“编辑所选珠子”，可调整尺寸、旋转、替换、与下一颗换位或删除。细线选中轮廓跟随珠体，不使用矩形操作框。拖到盘边不会删除，明确拖到删除区才移除。
6. 撤销／重做支持排布操作。画布取得焦点后，PageUp／PageDown 选择珠子，方向键移动或调整顺序，Delete 删除，Ctrl+Z／Ctrl+Shift+Z 撤销／重做。
7. 实时用量在盘下方；BOM 可展开查看。选择“展示”隐藏编辑控件；“导出实排图片 PNG”保存真实画布，不生成替代图片。
8. 给新设计使用独立名称再保存。重用已有名称会更新同名草稿；需要保留旧版本时先改名。载入草稿恢复每颗珠子的身份、来源、规格、旋转和排布。

## 素材与尺寸的诚实边界

- 原始“素材”文件夹的 13 张照片与后续抠图压缩包是两批清单。后者含 257 个衍生素材：251 个可选、5 个弱质量排除、1 个参考专用；另有 2 个保留的旧素材，所以实际可加载图片为 253 张。
- 150 个衍生素材从原图重新裁切，107 个只规范化已有裁切。并非 257 种水晶，也不宣称全部是经过认证的实拍。
- 原图文字只用于精确标签对应，不能证明矿物身份、珍珠种类、品质、采购尺寸或价格。未匹配素材在“本地素材”中保留原图编号和位置。
- 水晶目录 18/23 个主图有本地来源；彩虹月光石、锂辉石、血石、彩虹黑曜石及通称“发晶”仍是明确标注的生成参考图。等级比较图、配饰与包装未因本轮全部换成实拍。
- 透明 PNG 保留来源纹理和非圆轮廓，但已烘焙的光照／浅色边缘不能随背景重新物理渲染。部分已有裁切不能恢复原始外轮廓。
- 尺寸是沿串线方向的虚拟尺寸。内圈使用平均厚度近似；异形件孔位、厚度、穿线损耗和佩戴松紧仍需实物打样。未知成本不是零元。
- 多圈圆盘采用分离的同心圈；直槽采用连续的交替正背行。没有声称模拟参考视频中自然垂坠、弹性线张力、手感或 3D 光照。

## 本地验证

依赖：Node 24，项目既有 Fabric 7.4.0、Sharp 0.35.4；QA 使用开发依赖 playwright-core 1.58.2 与本机 Chrome。没有第二个生产渲染器、Python GUI、云抠图或后台常驻调度。

```powershell
npm.cmd test
npm.cmd run validate
node scripts/qa-dual-mode-studio.mjs
```

浏览器全流程复验要求本机私有素材、`outputs/dual-mode-cutout-validation.json` 和 `work/dual-mode/preserved-before.json`；缺少来源时明确失败，不能用占位图冒充。QA 使用自己的临时端口、草稿和导出目录，结束时仅关闭自己的浏览器／服务，不使用或覆盖用户导出。

`outputs/dual-mode-studio-validation.json` 记录实际场景、图片解码、截图、运行错误、保护文件哈希与性能范围。真实截图／录屏位于本地 `outputs/visual/dual-mode/`，不随代码发布；素材位于本地资产目录，来源索引及处理清单与原图分开保存。

纯工程测试的尺寸／对比度夹具不依赖私有图片；浏览器依赖不可用时的单元测试跳过不等于真实 UI 验收通过。最终状态以当前轮真实报告为准，不沿用旧测试数字。
